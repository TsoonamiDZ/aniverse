# أنيقا · موقع أنمي احترافي

موقع أنمي عربي (RTL) كامل المزايا: سلايدر سينمائي، بطاقات بتقييمات، صفحات تفاصيل
بالقصة العربية (من ويكيبيديا العربية)، مشغّل فيديو متعدد المزوّدين والجودات، وبحث حي.

**قاعدة البيانات مضمنة بالكامل** (2,187 أنمي · 25,866 حلقة · 149,244 رابط مشاهدة)
مستخرجة من okanime.xyz، ومُثراة ببيانات AniList/MyAnimeList + ويكيبيديا العربية.

## التشغيل على حاسوبك

### المتطلّبات
- [Bun](https://bun.sh) (وقت تشغيل JavaScript) — أو Node.js 20+

### الخطوات
```bash
# 1. فك ضغط الحزمة
unzip aniqa-site.zip
cd aniqa-site

# 2. تثبيت الاعتمادات
bun install   # أو: npm install

# 3. (اختياري) مزامنة قاعدة البيانات مع مخطط Prisma
bun run db:push

# 4. تشغيل الموقع
bun run dev
```

افتح **http://localhost:3000** في متصفّحك.

## المزايا

- **الصفحة الرئيسية**: سلايدر سينمائي بخلفية بانر عريضة، تقييمات ★/10، تصنيفات،
  بطاقات احترافية، بحث حي، فرز (الأكثر رواجاً / الأعلى تقييماً / الأكثر حلقات /
  أبجدي / اكتشاف).
- **صفحة الأنمي**: قصة عربية (من ويكيبيديا)، تصنيفات عربية، استوديو، حالة، سنة،
  مدة، روابط MAL وAniList، زر الإعلان (trailer)، وقائمة حلقات.
- **صفحة المشاهدة**: مشغّل iframe + مُحدِّد مزوّدين وجودات (FHD/HD/SD) + تنقّل
  بين الحلقات + قائمة جانبية.
- **مبدّل ثيم** داكن/فاتح.

## أداة التحديث (الفحص ثم التحديث)

في شريط الموقع العلوي، زر **«تحديث»**:

1. **فحص**: يفتح خرائط okanime، يكتشف الأنميات/الحلقات الجديدة، ويعرضها في
   نافذة كقائمة (عناوين + بوسترات + عدد روابط المشاهدة).
2. **تحديث قاعدة البيانات**: تضغط الزر فيُدرج الجديد فعلاً → يظهر مباشرةً على
   الموقع.

الأداة idempotent وقابلة للاستئناف — إعادة التشغيل تتخطّى الموجود.

### تشغيل الأداة من الطرفية (اختياري)
```bash
bun run scripts/sync-okanime.ts                 # مزامنة كاملة
bun run scripts/sync-okanime.ts --dry-run       # تقرير فقط
bun run scripts/sync-okanime.ts --limit 50     # أول 50 حلقة جديدة
bun run scripts/sync-okanime.ts --since 2026-10-01
```

## سكريبتات إثراء إضافية (اختيارية)

- `scripts/import-catalog.ts` — استيراد فهرس okanime الكامل إلى SQLite (إن بدأت
  من قاعدة فارغة).
- `scripts/enrich-anilist.ts` — إثراء ببيانات AniList/MyAnimeList (تقييم، تصنيفات،
  بانر، إعلان، استوديو...).
- `scripts/enrich-ar-wiki.ts` — إثراء بالقصة العربية من ويكيبيديا العربية.

## البنية التقنية

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4** + **shadcn/ui**
- **Prisma ORM** + **SQLite** (ملف `db/custom.db`)
- **TanStack Query** لحالة الخادم، **Zustand** للعميل، **framer-motion** للحركات
- **sonner** للإشعارات، **next-themes** للثيم

## ملاحظة قانونية

الموقع فهرس لروابط مشغّلات الأنمي المُجمَّعة علنًا من okanime.xyz. لا يستضيف أي
ملف فيديو؛ التشغيل عبر مُضمّنات المزوّدين. البيانات الوصفية (تقييم، تصنيفات، قصة
عربية) من AniList/MyAnimeList وويكيبيديا العربية. لأغراض الفهرسة والمعاينة.
